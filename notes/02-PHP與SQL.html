誰是 PHP？誰是 SQL？

在 members/02-api_register.php 這類註冊 API 裡，同一行畫面常同時出現 $pdo、->exec() 與夾在括號裡的 $sql。乍看全寫在一起，其實是兩種身分：PHP 負責動手，SQL 是被打包送出的指令。

身分鑑定：執行者與指令內容

  1. 鑑識成功

    誰是 PHP？（執行者）

    範圍：$pdo、->、exec() 與結尾分號 ;。

    怎麼認：

    • 字首有錢字號 $（變數）→ PHP。
    • 用箭頭 -> 呼叫動作 → PHP。
    • exec() 是 PHP 內建函式（動作）。

    職責：坐在電腦裡的「執行官」，負責發動命令。

  2. 鑑識成功

    誰是 SQL？（被執行的指令內容）

    範圍：括號裡的 $sql 字串。

    怎麼認：

    • $sql 雖是 PHP 變數（標籤 $），箱子裡裝的是上一段寫的 "insert into members..." 那串英文。
    • 內容是 insert into、select、delete 等資料庫語法 → 本質是 SQL 指令。

    職責：被打包好的「信件內容」，自己不動；須躺在 PHP 的 exec() 裡，由 PHP 發射到資料庫。

一秒區分結論

PHP 是動詞與工具（例如：$pdo->exec()，PHP 負責動手執行）。

SQL 是名詞與原料（例如：$sql，被執行的 SQL 指令字條）。
